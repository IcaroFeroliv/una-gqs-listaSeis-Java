# Gerador de Citações Estoicas 🏛️

Um programa simples em Java desenvolvido para praticar conceitos fundamentais de controle de versão locais e web utilizando Git e GitHub. 

## Sobre o Projeto

Este repositório contém o arquivo `GeradorEstoico.java`, que exibe uma citação aleatória de grandes pensadores do estoicismo (como Sêneca, Marco Aurélio e Epicteto) a cada execução. O objetivo principal deste código não é a complexidade lógica, mas sim fornecer uma base funcional para testar comandos de versionamento, como *commits*, *branches*, *merges* e *pull requests*.

## Funcionalidades

- Sorteio aleatório de frases a partir de um *array* interno.
- Saída formatada diretamente no terminal.
- Código de arquivo único, facilitando a compilação rápida sem necessidade de IDEs complexas ou gerenciadores de dependência.
